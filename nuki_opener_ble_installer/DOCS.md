# Nuki Opener BLE Installer

Копирует интеграцию «Nuki Opener (Bluetooth)» в `/config/custom_components/nuki_opener_ble`.

1. Нажмите **Запустить**. Приложение скопирует файлы и сразу остановится — это нормально.
2. Перезапустите Home Assistant (*Настройки → Система → Перезапуск*).
3. Добавьте интеграцию: *Настройки → Устройства и службы → Добавить интеграцию → Nuki Opener (Bluetooth)*.

Чтобы обновить интеграцию: обновите приложение, запустите его ещё раз и перезапустите Home Assistant.
Приложение можно удалить после установки — интеграция останется.
